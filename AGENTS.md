Install the matching GeckoLib loader jar on clients **and dedicated servers**; never install/shade the common API jar. Development and production GameTest tasks provision it automatically. Loader dependencies and convention plugins are configured in the Gradle files; do not replace their conventions with a second build/test path.

### In-game development commands

- `/genshin` reports the loaded mod version.
- `/genshin managed on|off|status` requires operator level 2. The switch covers the entire saved world/all dimensions, persists in overworld saved data and restores previous gamerules when switched off.
- `/genshin overlay apply` requires operator level 2 and managed mode. Installs/persists the versioned Mondstadt/Starfell/Windrise binding, original interactable Statue/Waypoint entities and Lv8 camps; idempotent deterministic IDs, **no map-block edits**. A fresh disposable copy made with `python3 scripts/map-port/port-map.py make-playtest` enables managed mode/applies the overlay on first load. Coordinates, tour evidence and source corrections: [docs/map-landmarks.md](docs/map-landmarks.md); launch procedure: [map-port README](scripts/map-port/README.md#managed-mondstadt-playtest). Never use the destructive arena command on the purchased map.
- Right-click a nearby travel obelisk to activate it for your player. **M** (rebindable) or `/genshin teleport` opens the unlocked destination list; free travel is allowed out of overworld combat and is not healing. Statues revive nearby fallen members at rounded 35% without spending reserve and, after two seconds within the adapted 6-block radius, heal toward 100% using the world's shared reserve (5000 capacity per globally unlocked physical Statue;1% regeneration every 15 real-time seconds). Wipe Revive uses the nearest player-unlocked point at final death, rounded 35% HP; no-unlock fallback is overlay arrival. Repeatable camp members return 12 real-time hours after death, including across reload/reapply; Lv8/shooter substitution/Windrise roster/timer origin are named adaptations.
- `/genshin arena` requires operator level 2 and a player source. **Destructive:** rewrites a fixed 50×50×6 volume around that player with a smooth-stone floor, a one-block border and cleared air; enables managed mode, teleports the player to the centre and sets adventure mode. Use generated/disposable development worlds only.
- `/genshin camp hilichurl [count] [level]` requires operator level2/player source; command-only club camp (default3,count1–12,defaultLv8,level1–20). `/genshin arena camp` places threeLv8 hilichurls at the far side. Lv8 remains a WL0 adaptation: pinned7.1 dump did not identify exact Starfell/Windrise/gate spawns. Numeric HP/ATK/DEF are exact exported base×level curves, not party level or flat120ATK; Lv8=237.81997824HP/103.56204816ATK/540DEF. [Datamine pin/tables](spec/mechanics/datamine.md). Managed-only survival/adventure aggro, half-second raised-club wind-up/chase/anchor reset unchanged. Explicit spawns ignore natural-spawn disable; `/summon genshininminecraft:hilichurl` usesLv8/own anchor.
- `/genshin aura pyro|cryo|electro|hydro <gauge>` requires operator level 2, a player source and managed mode. Applies the positive **untaxed** gauge to the aimed combat target within 16 blocks, otherwise the nearest eligible enemy in that range. Players and all player-owned puppets are excluded. This debug source enables Hydro playtesting (including Electro-Charged/Frozen/Vaporize); the starter party has no Hydro character. Aura tax/reaction/coexistence rules still apply; the command is not talent damage or an application-ICD hit.

Hunger, natural regeneration, natural spawning, environmental fire spread and mob griefing are disabled; weather/day-night remain unchanged. See [the detailed decision](docs/decisions.md#2026-10-04--saved-world-managed-mode-and-bounded-developer-arena).

### Private headless clients

Start agent sessions using `scripts/omp-isolated.sh`. Never use the owner's display, session D-Bus, clipboard, input devices or audio services. Keep all spawned clients and servers inside the isolated session's resource limits (12 GiB RAM and 3 CPUs); size JVM heaps accordingly.

**This machine has Xvfb, not sway or grim.** `runProductionClientGameTest` manages its own Xvfb display. For an interactive development client, wrap it in a private Xvfb display with software OpenGL:

```sh
ALSOFT_DRIVERS=null LIBGL_ALWAYS_SOFTWARE=1 \
xvfb-run -a --server-args="-screen 0 1280x720x24 -nolisten tcp" \
./gradlew --no-daemon :fabric:runClient
```

Xvfb needs the OpenGL/X11 runtime libraries listed in [README.md](README.md). Recording through `:fabric:recordClientGameTest` additionally needs ffmpeg and PipeWire tooling; never connect recording to the owner's audio session. The existing Fabric client GameTest joins a dedicated server and asserts that the client initializer, world and player are available.

### Dedicated two-client co-op smoke

Run **only after the Gradle gate exits**, never alongside it:

```sh
python3 scripts/coop-smoke/run.py
```

The script prepares Loom's existing development launch classpaths in one Gradle invocation, then exits Gradle before starting one loopback-only disposable dedicated server (3GiB heap) and two separate client JVMs (1536MiB each), each under its own `xvfb-run -a`1280×720 display with `ALSOFT_DRIVERS=null LIBGL_ALWAYS_SOFTWARE=1`, dead session D-Bus and private runtime/game directories. No owner's display/audio/input/clipboard or purchased map is used. Default deadline 900s; `--timeout <seconds>` changes it. Logs, world, stage assertions, JSON result and `screenshots/coop-{host-sees-lisa,guest-sees-kaeya}.png` are under a fresh ignored `run/coop-smoke/<timestamp>/`.

The test-only Fabric driver lives in `src/gametest`, is enabled only by `genshin.coopSmoke`, and is absent from release jars. Both real clients join the external dedicated server, assert the other's actual GeckoLib extraction and name/active HP HUD, then capture screenshots. Each sends genuine combat intent against one shared hilichurl; Kaeya triggers Superconduct on Lisa's aura. The guest's allocated characters fall through actual server damage, the host attacks while the guest is dead, and the guest requests ordinary vanilla respawn at 35% without changing the host's HP. The launcher waits for the first client's recorded `DISPLAY` before starting the second and asserts their displays differ: this machine's `xvfb-run -a` precomputes a free number and races if both wrappers start together. ### Repeatable sound review

Run only after the Gradle gate exits, never alongside it:

```sh
python3 scripts/sound-review/run.py
```

The launcher puts itself and every Gradle/JVM/Xvfb/PipeWire/WirePlumber/ffmpeg child in `systemd-run --user --scope -p MemoryMax=12G -p CPUQuota=300%`. It prepares Loom's development GameTest classpath, exits Gradle, then records the opt-in test-only `SoundReview` sequence in a disposable loopback arena. Private Xvfb uses `-displayfd`; private PipeWire has no hardware-device modules and WirePlumber uses its policy-only profile. The client uses only that Pulse null sink. No owner's display, audio, D-Bus, clipboard or purchased map is used.

Requires Java25, Xvfb, ffmpeg/ffprobe, PipeWire/Pulse, WirePlumber and pactl. Default sequence deadline1800s; `--timeout <seconds>` changes it. Fresh ignored `run/sound-review/<timestamp>/` contains `sound-review.mp4`, wall-clock-PTS raw MKV, exact SoundEngine receipts in `events.tsv`, `cues.md`, `report.json` (per-event rendered levels, recorded full/busy levels, audio packet gaps and busy counts), all-variant `validated-candidates.json`, process logs and `capture.json`. MUSIC/RECORDS are muted, gameplay/master100%; no normalization. `aresample=async=1000:min_hard_comp=0.01` repairs timestamp gaps; the raw copyts epoch is recovered with ffprobe and both tracks shifted together during a single-input MP4 remux. Signal levels do not claim anybody listened or that overlapping timbres are perceptually distinguishable.

Capture ffmpeg must include **x11grab and Pulse inputs** (the system's reduced ffmpeg on this NixOS host does not). `--ffmpeg <executable>` or `FFMPEG=<executable>` selects it; otherwise the launcher checks installed ffmpeg and, on Nix, resolves `nixpkgs#ffmpeg-full` when necessary. Asset decoding/ffprobe can use the reduced system build. Display/audio capability checks happen before any client launch.

By default the historical review in `run/sound-review/20261009-234316/` is analyzed into `before-report.json`/`before-after.md` beside the new capture; `--baseline <directory>` chooses another historical report. Re-run asset/receipt analysis without a new client using `python3 scripts/sound-review/run.py --analyze run/sound-review/<timestamp>`. This driver stays in `fabric/src/gametest`, is absent from release jars, and is selected only by `GENSHIN_SOUND_REVIEW`; it does not replace the required connected client gate.

Only the opt-in recording fixture disables Minecraft's tick watchdog (`max-tick-time=0`): Fabric's phased test server can intentionally wait on the software-rendered client/test thread longer than ordinary real-time ticks. The launcher retains its finite deadline and every required accepted-action assertion. Ordinary server GameTests/the connected gate do not get this override. llvmpipe is limited to two worker threads and the combined test client/server JVM uses3GiB/SerialGC under the unchanged12GiB/3CPU scope.



## Module layout

- `common/src/main/java`: shared implementation. Plain-Java rules belong here and have **no Minecraft types**: stats, damage, elements, ICD, abilities, ordered event timelines, cooldowns, progression and save schemas. Keep them deterministic with seeded randomness and stable ordering.
- `common/src/main/resources`: shared resources, translations and mixin configurations. The server mixins protect managed hunger, block placement and farmland; both loader metadata files reference the shared configurations.
- `common/src/gametest`: shared server GameTest bodies.
- `fabric/`: thin Fabric entrypoints and event wiring; `src/client` holds client entrypoints, `src/test` JUnit tests, and `src/gametest` server registrations plus the client GameTest.
- `neoforge/`: thin NeoForge entrypoints and event wiring; `src/gametest` registers the shared server tests and provides their test-instance JSON files.
- `spec/`: sourced mechanics research for the pinned Genshin version and the fidelity ledger.
- `tools/models/generate.py`: deterministic original character geo/animation/PNG authoring and generated credits; generated runtime assets are checked in. Python 3 stdlib only; normal Gradle builds do not invoke Python.
- `docs/`: the durable brief, decisions, release documentation and existing icon provenance.
- `reference/map/*.zip`: pristine, git-ignored map archives. **Read-only.**

## Invariants

- Every feature works on **both Fabric and NeoForge**, including integrated and dedicated servers. Keep loader modules thin and shared logic in `common/`.
- The **server is authoritative** for damage, elemental state, cooldowns, energy, stamina, inventory, rewards, progression, quests and persistence. Clients send intent; prediction must not grant authority.
- Client-only Minecraft classes stay out of dedicated-server paths. Separate input, camera, rendering, HUD and screens from rules and server adapters.
- Mechanics are pinned to Genshin 7.1, as recorded in the brief. Re-pin only by a dated decision; never silently mix versions. Test expectations come from public sources and owner observations, not implementation output.
- Never weaken tests to obtain a pass. Accepted bugs need a reproduction and regression test. Keep server GameTests on both loaders and the Fabric client join/in-world test exercised.
- Do not modify `reference/map/*.zip`. Extract or upgrade only into disposable, git-ignored copies. **Never commit map data, extracted worlds or third-party packs.** Before the map port, develop in a generated flat test arena.
- Private use only: no public hosting, publishing or distribution before the permissions/legal review described in the brief. No leaked code, extracted game assets or connections to HoYoverse services/accounts. Purchased map/model references are not shipped.
- Environmental fire must never destroy map blocks. Record other intentional vanilla-behaviour changes and fidelity adaptations.
- Prefer the smallest concrete design; no generic engine or scripting language without a demonstrated need.
- Keep runtime worlds, screenshots, recordings and logs under git-ignored directories.
- **Never set or override git identity** in repository config, on the command line, or through `GIT_AUTHOR_*`/`GIT_COMMITTER_*`. Never hand an identity override to a delegated task.
